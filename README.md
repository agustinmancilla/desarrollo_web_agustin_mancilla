# Tarea 1 - Desarrollo Web
## Descripción
Esta tarea consiste en la implementación de una página web HTML con CSS, y funciones útiles escritas en JavaScript. La página consiste en una aplicación para coordinar y realizar la adopción de perros o gatos.

## Decisiones tomadas
-Varias de las funciones, principalmente las de validación, fueron tomadas y modificadas de los auxiliares.

-Para el diseño, hice un cierto uso de flexbox, para que la página no se viera demasiado plana.

-Agrupé ciertas funciones útiles para el formulario en un solo archivo JavaScript
